# 🎯 BoVW_SVM

## 📌 Descrição

Este projeto implementa um **pipeline de Bag of Visual Words (BoVW)** para extração de descritores visuais e utiliza um **classificador SVM** para reconhecimento de padrões em imagens.

A ideia central é transformar imagens em representações vetoriais usando **SIFT + BoVW** e, em seguida, treinar/testar um modelo baseado em **Support Vector Machines**.

---

## 🛠️ Tecnologias Utilizadas

* 🐍 **Python**
* 📷 **OpenCV**
* 🔢 **NumPy**
* 📊 **Scikit-Learn**

---

## 👥 Equipe & Responsabilidades

* **Joaquim** → Extração dos descritores **SIFT**
* **Lincon** → Classificação com **SVM** usando os descritores

---



💡 *Este projeto é uma introdução prática ao uso de técnicas clássicas de Visão Computacional para classificação de imagens.*
